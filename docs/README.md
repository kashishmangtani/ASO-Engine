## Conventions
- Anything marked **TBD** is waiting on a decision. Once it's decided, update the document and add a row to the decisions log.
- Placeholders in `[square brackets]` (such as `[Platform Name]` and `[price]`) are to be filled in.
- Don't publish claims or statistics we can't source. Collect real client results for case studies instead.
